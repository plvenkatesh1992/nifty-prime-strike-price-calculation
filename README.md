# nifty-prime-strike-price-calculation
nifty prime strike settlement price CALL/ PUT calculation

Download and unzip the source code in any folder in your machine like D:/project/
Eg: Your project path will be: D:/project/nifty-prime-strike-price-calculation

Commands to run the app.
Open Windows Command Prompt or MacOs Terminal

Step 1: navigate to the application folder path
# cd D:/project/nifty-prime-strike-price-calculation

Step 2: You should run this command only once.[One Time Setup]
# npm i

Step 3:
# npm run dev
